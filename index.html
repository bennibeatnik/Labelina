      Connection help

      USB: plug the printer in and pick the entry that says USB. Labelina talks to the printer directly, so it can read the tape and confirm each print, and Brother's driver and P-touch Editor keep working. The via Windows print queue entry is a fallback; jobs can get stuck in the queue there.

      Bluetooth: pair the printer in Windows Bluetooth settings first, then press Refresh. Bluetooth can also read which tape is loaded. Labelina reconnects to the last printer automatically.

      Bluetooth: pair the printer in your system's Bluetooth settings first. On Windows it then appears as a COM port; pick it from the list.

      USB on Windows: the Brother driver keeps the printer to itself. To use USB from the browser, switch the printer to the WinUSB driver (for example with Zadig). Brother's own software won't see it until you switch back. The Labelina desktop app doesn't have this problem.

      Orientation: print the test label. If the text comes out upside down or mirrored, tick Flip or Mirror.

      Direct printing needs Chrome or Edge on a desktop and a site served over HTTPS (or localhost).

      Direct printing works with Brother P-touch tape. For this media, download a PDF, PNG or ZPL file below.
